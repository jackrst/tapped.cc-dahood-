# 🔫 tapped.cc – Ultimate Da Hood HvH Script

[![Version](https://img.shields.io/badge/version-2.0.1-blue)](https://github.com/jackrst/yapped.cc-dahood-/releases)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

## 🚀 Features

| Category | Features |
|----------|----------|
| **Ragebot** | Silent Aim (Rage/Legit), FOV Circle, Aim Part Select, Kill Aura w/ Holographic Bubble, Auto Shoot, Triggerbot |
| **HvH** | Walkable Desync, Velocity Desync, Network Fake Lag, Anti-Stomp (Defov), Airshot Resolver, SpinBot |
| **Visuals** | ESP (Box/Name/Health/Distance/Snapline/Tracer/HeadDot/Skeleton/Weapon), Chams, Glow Tracers |
| **Effects** | Orbiting Target Effect, Desync Visual (Fake Character), Hitbox Visual |
| **Movement** | Fly, Noclip, Speed Control, Bunny Hop, Auto Strafing, Auto Crouch |
| **Smart** | Auto Weapon Select, Auto Stomp, Target Indicator (Draggable) |

## ⌨️ Keybinds

| Key | Action |
|-----|--------|
| `K` | Open UI Menu |
| `X` | Toggle Ragebot |
| `E` | Stomp Target |

## 📦 Installation

1. Copy the contents of `tapped.lua`
2. Paste into your executor (Synapse X, Krnl, ScriptWare, etc.)
3. Execute

## ⚠️ Requirements

- Roblox executor with `loadstring` support
- Internet connection for Starlight UI loading
